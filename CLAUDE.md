# Cargoe — правила работы

## Контекст между сессиями

**Перед любой работой прочитай [PROJECT_JOURNAL.md](PROJECT_JOURNAL.md) целиком.** Это живой журнал проекта: бизнес-контекст, принятые решения и их обоснования, фазы, проблемы, открытые вопросы.

**Обновляй журнал в той же сессии, в которой делаешь работу**, не «потом»: закрытая задача — в §9 + строка в §10, новая проблема — в §11, вопрос заказчику — в §12. Правила ведения — в §0 журнала.

## Язык общения

Общение на **русском**. Комментарии в коде — на русском или английском (по стилю файла). Контент сайта — pt / en / ru / uk.

## Что за проект

Сайт компании **Cargoe** (Лиссабон) — переезды под ключ (mudanças). Заказчик: Паша, друг. Подробности — §1 журнала.

**Три вещи, по которым оценивается любое решение:**
1. **SEO** — страница должна индексироваться и ранжироваться (SSG/ISR, мета, hreflang, schema.org).
2. **Скорость** — бюджеты в §8 журнала; лишний килобайт JS и неоптимизированная картинка недопустимы.
3. **Заказчик правит контент сам** — ничего из того, что Паша захочет поменять (текст, фото, цена, услуга), не должно быть захардкожено в коде.

**Сроков нет.** Делаем качественно и на вырост. Не срезаем углы.

## Правила кодирования

- **TypeScript strict** — никаких `any`, `as unknown as`, `@ts-ignore`.
- **Серверные компоненты по умолчанию**; `"use client"` — только там, где нужна реальная интерактивность.
- **Ноль хардкода в стилях** — отступы, радиусы, цвета, типографика только через токены темы (Tailwind `@theme` + CSS-переменные).
- **Ноль хардкода в контенте** — тексты через i18n, контентные данные из CMS.
- **Изображения** — только через оптимизированный конвейер (§6 журнала), `next/image` с точными `sizes`.
- ESLint + Prettier перед финалом.

## Локальный скилл дизайна

В проект локально установлен сторонний скилл **ui-ux-pro-max** (база стилей/палитр/шрифтов/UX-правил, репо `nextlevelbuilder/ui-ux-pro-max-skill`, v2.13.0). Лежит в `.claude/skills/ui-ux-pro-max/`, в git не попадает.

Переменной `CLAUDE_PLUGIN_ROOT` здесь нет — запускать по относительному пути от корня проекта:

```bash
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<запрос>" --domain <domain>
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "<запрос>" --design-system -p "Car-Go"
```

Выдача — **рекомендация, а не приказ**: сверяем с §1–§2 журнала (премиальность, доверие, спокойствие) и отбрасываем неподходящее.
